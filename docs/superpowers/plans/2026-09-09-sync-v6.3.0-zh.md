# Sync v6.3.0 Chinese Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Fork 同步到上游稳定版 v6.3.0，并完成新增与变更内容的增量汉化。

**Architecture:** 在上游 v6.3.0 提交之上形成独立汉化提交，再合并回 Fork 同步分支。代码、配置、测试直接继承上游；用户文档、技能正文和提示词按现有中文风格翻译。

**Tech Stack:** Git、Markdown、JSON、Bash、Node.js、Python

**Spec:** `docs/superpowers/specs/2026-09-09-sync-v6.3.0-zh-design.md`

## Global Constraints

- 只同步 `upstream/main` 的 v6.3.0，不包含 `upstream/dev`。
- 不新增第三方依赖。
- 不改变代码、配置和测试的运行语义。
- 命令、路径、API、工具名称和精确测试字符串保持英文。
