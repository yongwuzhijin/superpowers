# 同步上游 v6.3.0 并增量汉化设计

## 目标

将 Fork 的 `main` 从 v6.2.0 同步到上游 `upstream/main` 的 v6.3.0，同时延续当前 Fork 的中文化策略。

## 范围

- 保留 v6.3.0 的全部代码、配置、测试、新 Harness 支持和版本号更新。
- 汉化 v6.3.0 新增或修改的用户可读文档、技能正文和 Agent 提示词。
- 保留命令、路径、代码、API 名称、工具名、frontmatter 的 `name` 值以及必须精确匹配的英文测试文本。
- 更新 `README.zh-CN.md`，使其覆盖 v6.3.0 新增的 Devin CLI 与 Hermes Agent 安装说明。
- 不同步 `upstream/dev` 中尚未发布的变更。

## 集成方式

从 `upstream/main` 创建 v6.3.0 汉化提交，再将该提交合并进 Fork 的同步分支。这样既保留完整上游历史，也让汉化改动集中、易于审查，并与 v6.2.0 的同步历史保持一致。

## 验证

- 检查版本号均为 `6.3.0`。
- 检查所有上游新增文件均存在。
- 对比汉化结果与 `upstream/main`，确认非文档代码没有意外语义改动。
- 运行仓库内无需外部 LLM 凭据的插件、脚本和单元测试。
- 检查工作区无冲突标记、JSON/YAML/Markdown 基础格式正常。
